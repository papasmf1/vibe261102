# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 개인의 기술 역량, 프로젝트, 경력을 소개하는 포트폴리오 웹사이트 |
| 연락처 | papasmf1@gmail.com |
| 주력 분야 | Python, HTML5, iOS 앱 개발 |
| 작성일 | 2026-11-03 |

## 2. 목표

- 방문자(채용 담당자, 클라이언트, 협업 개발자)가 **1분 안에** 개발자의 주력 기술과 대표 프로젝트를 파악할 수 있다.
- 이메일을 통해 바로 연락할 수 있는 명확한 경로를 제공한다.
- 데스크톱과 모바일 모두에서 빠르고 깔끔하게 동작한다.

### 비목표 (Non-goals)

- 블로그/CMS 기능 (1차 범위 제외)
- 회원가입, 로그인 등 사용자 계정 기능
- 백엔드 서버 및 데이터베이스

## 3. 타깃 사용자

| 사용자 | 니즈 |
|--------|------|
| 채용 담당자 / 인사팀 | 기술 스택, 경력, 이력서를 빠르게 확인 |
| 외주 클라이언트 | 완성된 앱/웹 결과물 확인, 견적 문의 |
| 동료 개발자 | GitHub 코드, 기술적 깊이 확인, 협업 제안 |

## 4. 주요 기능 (페이지 구성)

단일 페이지(One-page) 스크롤 구조, 상단 고정 내비게이션으로 각 섹션 이동.

### 4.1 Hero (메인 소개)
- 이름, 한 줄 소개 (예: "Python · HTML5 · iOS 앱을 만드는 개발자")
- 주력 기술 배지: **Python**, **HTML5**, **iOS (Swift / SwiftUI)**
- CTA 버튼: `프로젝트 보기`, `연락하기`

### 4.2 About (자기소개)
- 프로필 사진
- 간단한 자기소개 및 개발 철학
- 경력 연차, 관심 분야

### 4.3 Skills (기술 스택)
주력 분야를 중심으로 카테고리별 정리.

| 카테고리 | 기술 |
|----------|------|
| **Python** | Python 3, FastAPI / Flask / Django, 데이터 처리(pandas), 자동화 스크립트 |
| **Web (HTML5)** | HTML5, CSS3, JavaScript, 반응형 웹, 웹 표준/접근성 |
| **iOS** | Swift, SwiftUI, UIKit, Xcode, App Store 배포 |
| 기타 도구 | Git / GitHub, VS Code, Figma |

- 주력 3개 분야는 시각적으로 강조 (카드 상단 배치, 아이콘 포함)

### 4.4 Projects (포트폴리오)
- 프로젝트 카드 그리드 (최소 3~6개)
- 각 카드 구성: 썸네일, 프로젝트명, 요약, 사용 기술 태그, 링크(GitHub / 데모 / App Store)
- 기술 태그 필터: `전체` / `Python` / `Web` / `iOS`

### 4.5 Experience (경력 / 학력)
- 타임라인 형태로 경력, 교육, 자격증 표시

### 4.6 Contact (연락처)

- GitHub, LinkedIn 등 외부 링크 아이콘

### 4.7 Footer

## 6. 기술 스택 (구현)

- **HTML5 + CSS3 + Vanilla JavaScript** (빌드 도구 없이 정적 사이트)
- 프로젝트 데이터는 `data/projects.js`로 분리해 쉽게 추가/수정 (서버 없이 `file://`로 열어도 동작하도록 JSON 대신 JS 사용)
- 배포: GitHub Pages 또는 Netlify / Vercel (정적 호스팅)
